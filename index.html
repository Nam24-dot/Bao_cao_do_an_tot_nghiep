Tổng quan

CPU điều khiển AES như một ngoại vi bộ nhớ

CPU ghi key và plaintext vào vùng thanh ghi AES tại 0x800000xx, phát lệnh init/next, chờ trạng thái ready/valid, đọc ciphertext 128-bit rồi xuất kết quả ra vùng LED IO.

RV32IPipeline 5 tầng, hazard và forwarding
Custom AESAES-128 với mask, permutation và rotate
DE10SW chọn word/byte, LEDR hiển thị dữ liệu

Kiến trúc

Luồng xử lý trong SoC

CPU.v giải mã truy cập AES và LED IO trong tầng MEM. Các lệnh load/store thông thường đi tới DataMemory, còn truy cập 0x800000xx đi tới AES accelerator và truy cập 0xffff000x đi tới SimpleIO.

Phần mềm

Nhập key/data và tạo firmware cho CPU

GUI trong Software/Custom_AES_OneFile_GUI.py nhận key và input block 128-bit, tính kết quả Custom AES, rồi sinh risc_aes.hex gồm các lệnh RISC-V để CPU nạp key, nạp block, chạy AES và ghi đủ RESULT0..RESULT3 ra LED registers.

python .\Software\Custom_AES_OneFile_GUI.py Tạo risc_aes.hex cho CPU risc_aes.hex → InstructionMemory

Mô phỏng

Regression bằng QuestaSim 10.2c

Bộ test gồm test ISA cho tập lệnh CPU đang hỗ trợ và test CPU-AES kiểm tra toàn bộ đường đi từ firmware, CPU pipeline, AES accelerator tới LED IO.

powershell -ExecutionPolicy Bypass -File ".\Simulation Scripts\run_questa_all.ps1" TEST_PASS tb_cpu_isa TEST_PASS tb_cpu_aes
Lưu ý về thư mục kết quả: `Ket_qua_va_Waveform/` đang chứa ảnh/waveform cũ. Cần xuất lại waveform bằng script hiện tại trước khi dùng làm minh chứng trong báo cáo.

FPGA

Xem đủ ciphertext 128-bit bằng switch

DE10 Standard chỉ có 10 LED đỏ, nên kết quả AES được xem theo từng byte. SW[9:8] chọn RESULT0..RESULT3, SW[7:6] chọn byte trong word, và LEDR[7:0] hiển thị byte đang chọn.

Lưu ý về ảnh FPGA: `Ket_qua_chay_tren_FPGA_DE10_Standard/` đang chứa ảnh/video cũ. Cần chụp lại sau khi nạp bản mới lên FPGA.
